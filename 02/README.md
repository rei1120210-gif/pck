## 🚀 快速啟動方式

你可以透過以下任一種方式立即啟動系統：

### 方式 1：一鍵點擊執行（最推薦）
- 直接在資料夾中雙擊執行 **`run_tutor.bat`**。
- 系統會自動檢查環境，啟動本地伺服器並自動開啟預設瀏覽器（Google Chrome、Edge 等）。

### 方式 2：使用 Python 啟動本地伺服器
在命令列（PowerShell 或 CMD）中執行：
```bash
python start_server.py
```
隨後在瀏覽器中打開：[http://localhost:8000](http://localhost:8000)

### 方式 3：直接開啟 HTML
- 直接滑鼠雙擊 **`index.html`** 檔案即可於瀏覽器開啟使用。

## 🌟 系統六大核心模組

1. **📊 學情大數據總覽 (Analytics & Radar)**
   - 整合成績、正答率、失分盲區與提分潛力四宮格。
   - 提供「電腦五大架構、CPU效能規格、記憶體快取階層、次級儲存、周邊I/O、多媒體顯示」六大維度 **Chart.js 雷達圖**。
   - 彙整家教名師學情綜合評語與三步提分處方籤。

2. **🔍 6大錯題深度精解 (Mistake Breakdown)**
   - 逐題對照政緯本次答錯的 6 道考題（第 3、10、15、16、17、22 題）。
   - 包含：學生原答 vs 正確答案、老師紅筆手寫評語原註記、盲區剖析、正確核心架構、名師深度解析、**記憶口訣**與應考行動指南。
   - 附帶「一鍵呼叫 AI 家教解惑」連動按鈕。

3. **🤖 AI 智慧家教即時對答 (Interactive Socratic Tutor)**
   - 模擬專屬資訊科技家教「小智老師」。
   - 支援「一鍵快捷發問」（SSD磁碟重組、SRAM vs DRAM、2.80GHz單位換算、MIPS縮寫、AMOLED自發光、記憶單元內存程式）。
   - 支援學生任意自由打字提問，家教即時以蘇格拉底啟發式與生活化比喻解答。
   - 支援 **Web Speech API 語音朗讀伴讀**，戴上耳機如同家教隨身輔導。

4. **🎯 靶向強化過關測驗 (Targeted Remedial Quiz)**
   - 針對 6 大扣分點設計的 6 題全新高頻模擬題。
   - 單題互動做答、即時核對答案、提供解題引導與完整解析。
   - 測驗完成後即時計算提分效果（從 76 分跨越至 100 分），並觸發全螢幕勝利慶祝灑花！

5. **📚 全卷 25 題庫 (Full 25 Exam Items)**
   - 完整收錄原測驗卷 25 題試題與選項。
   - 支援「全部試題」、「僅看錯題 (6)」、「僅看答對 (19)」即時篩選。
   - 包含詳細解析與語音朗讀按鈕。

6. **📷 原始試卷照片對照 (Original Exam Paper Photos)**
   - 內建兩張高清考卷原圖（第 1 頁與第 2 頁）。
   - 點擊可開啟全螢幕高解析燈箱，方便查看學生筆跡與老師紅筆批改原貌。

7. **🖨️ 學習診斷報告列印支援**
   - 點擊右上角「列印學情報告」按鈕，可直接匯出列印版或另存為 PDF，適合作為家長聯絡簿或課後複習教材。
